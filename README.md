FITFLOW 🏋️‍♂️

FITFLOW is a modern fitness and workout planner website built using only HTML5 and CSS3.
This project provides users with an easy way to manage workout schedules, diet plans, and fitness goals through a clean and responsive interface.

🌟 Features
🔐 Login & Signup Pages
🏠 Home Dashboard
💪 Weekly Workout Planner
🥗 Weekly Diet Planner
⚙️ Options / Settings Section
👤 User Profile Page
🌙 Dark Theme UI
📱 Responsive Design
✨ Smooth Navigation Using Anchor Links
🎨 Modern Card-Based Layout
🛠️ Technologies Used
HTML5
CSS3
